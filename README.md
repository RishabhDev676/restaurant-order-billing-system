# 🍽️ Restaurant Order and Billing System

A desktop-based Restaurant Order and Billing System developed using **Java Swing** for the graphical user interface. The application enables users to manage restaurant orders, calculate bills accurately, and generate receipts through a simple and user-friendly interface.

## 📌 Features

- Interactive Java Swing GUI
- Restaurant menu display
- Order placement
- Quantity validation
- Automatic bill calculation
- Itemized receipt generation
- Date & Time on receipt
- Input validation
- Clean and modular code structure

## 🛠️ Tech Stack

- Java
- Java Swing (javax.swing)
- NetBeans IDE
- Apache Ant

## 🚀 Getting Started

### Prerequisites

- Java JDK 17 or later
- NetBeans IDE (recommended)

### Installation

1. Clone the repository

```bash
git clone https://github.com/RishabhDev676/restaurant-order-billing-system.git
```

2. Open the project in NetBeans.

3. Build and run the project.
